✨ 核心能力

从音频引擎到系统集成，每一处都精心打磨

高性能音频引擎

基于 miniaudio 单头文件库，支持 MP3 / FLAC / WAV / OGG / AAC / M4A / WMA / Opus。

24-bit 直通

智能音乐库管理

自动去重、多歌手合并、全局搜索高亮、手动拖拽排序，五列自适应布局。

音质标签

完善的歌词系统

外部 .lrc / 嵌入式歌词，双语字幕，逐行高亮，预读偏移可调。

逐行高亮

深度 Windows 集成

SMTC 系统控件、NSD 灵动岛、Just Solo LyricServer 协议、系统托盘。

Win11 原生

播放控制

  • 5 种播放模式（顺序 / 循环 / 单曲 / 随机 / 关闭）
  • 全局快捷键（可自定义）
  • 进度条点击 / 拖动 seek
  • 支持热插拔：热插拔不影响音乐播放

收藏 & 历史

  • 收藏 / 取消收藏，持久化存储
  • 播放历史自动记录，上限 500 条
  • 启动自动恢复上次播放列表
  • 跨来源跟踪，智能去重

界面 & 体验

  • 毛玻璃播放详情页，圆形封面
  • 深色 / 浅色主题原生适配
  • 透明度可调，缩放动画
  • 系统原生标题栏（Win11 三色定制/Win10强制深色主题）

技术栈

  • C++17 + Qt 6.8.3
  • QML 现代界面，GPU 渲染
  • CMake 构建，MSVC 编译
  • HarmonyOS Sans SC 字体
