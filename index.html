项目简介

Just Solo 是一款追求简洁、高性能的本地音乐播放器。采用 C++ 高性能核心 + QML 现代界面， 无 Electron 依赖，内存占用低，冷启动迅速。

原生支持 Windows SMTC 系统媒体控件和 Just Solo LyricServer 媒体信息传输协议（基于 WebSocket）， 深度适配 NSD 灵动岛。 目前仅支持 Windows 平台，专注于纯本地音乐播放。内置基于 libcurl 的 OTA 在线更新功能。

功能特性

音频引擎

  • 基于 miniaudio 轻量库，替代 Qt Multimedia
  • 支持 MP3 / FLAC / WAV / OGG / AAC / M4A / WMA / Opus
  • 热插拔支持：设备插拔不中断播放
  • 流式播放，大幅降低内存占用

播放控制

  • 播放 / 暂停 / 停止 / 上一首 / 下一首
  • 5 种播放模式：顺序 / 列表循环 / 单曲循环 / 随机 / 关闭循环
  • 进度条支持点击拖动 seek
  • 全局快捷键（默认 Ctrl+Alt+Space 等，支持自定义）

音乐库管理

  • 导入方式：文件对话框 / 文件夹 / 拖放
  • 自动去重：保留音质更高版本
  • 多歌手分隔符统一（/ ; |｜ → 、）
  • 音乐搜索：标题/歌手/专辑模糊匹配

自定义播放列表

  • 侧边栏创建/重命名/删除
  • 从音乐库多选导入
  • 切换列表时确认弹窗
  • 持久化到 custom_playlists.json

收藏与历史

  • 收藏/取消收藏，持久化到 favorites_cache.json
  • 播放历史自动记录，上限 500 条
  • 播放列表启动自动恢复

歌词系统

  • 外部歌词：同目录同名 .lrc 文件
  • 嵌入式歌词：MP3 ID3v2 / FLAC VorbisComment
  • 双语字幕自动检测合并
  • 逐行高亮三色方案，歌词预读偏移可调

Windows 系统集成

  • SMTC 系统媒体接口（任务栏/锁屏/蓝牙）
  • NSD 灵动岛深度适配（每 500ms 推送）
  • LyricServer 协议（WebSocket，ws://127.0.0.1:47290）
  • 系统托盘、单实例检测、原生标题栏

迷你播放器 & 详情页

  • 独立小窗模式，始终置顶
  • 封面取色 + 毛玻璃背景
  • 播放详情页底部滑入滑出
  • 逐行高亮歌词展示

设置页面

  • 外观设置：循环模式/音量条透明度
  • 播放设置：歌词预读偏移、跨来源跟踪
  • 快捷键设置：捕获模式卡片
  • OTA 在线更新（基于 libcurl）

FAQ

这个项目支持哪些平台？

目前仅支持 Windows 10/11（64位），win7 暂未测试。暂时不计划支持其他平台，欢迎其他平台的贡献。

这个项目对比 AnyListen 等其他音乐播放器有什么区别？

本项目使用 Qt 框架，聚焦高性能、低占用，以本地音乐播放为核心，内置 OTA 在线更新功能，不提供音乐下载等网络服务。

这个项目会维护多久？

计划在 2026 年暑假内完成核心功能，后续进入 LTS 维护状态，继续维护和修复 bug。

这个项目的代码是否开源？

是的，代码永久开源免费，在 MIT License 下开源，在多个平台上提供镜像仓库。
