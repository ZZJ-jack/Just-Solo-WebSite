Just Solo 是一款追求简洁、高性能的本地音乐播放器。 采用 C++ 高性能核心 + QML 现代界面，无 Electron 依赖， 内存占用低，冷启动迅速。

< 150MB 平均内存占用
< 0.5s 冷启动时间
60fps 流畅 UI 渲染

✨ 功能特性

为纯粹的本地音乐体验而生

高性能音频引擎

基于 miniaudio 轻量库，支持 MP3 / FLAC / WAV / OGG / AAC / M4A / WMA / Opus 等主流格式，流式播放大幅降低内存占用。

C++ 核心

Windows 深度集成

原生支持 SMTC 系统媒体控件、NSD 灵动岛深度适配、Just Solo LyricServer 协议（WebSocket），系统托盘、全局快捷键一应俱全。

Win10/11

智能音乐库管理

支持文件对话框多选、导入文件夹、拖放导入，自动去重、音质优选，多歌手分隔符统一，全局搜索高亮定位。

高效管理

强大歌词系统

支持外部 .lrc 文件与嵌入式歌词（MP3 ID3v2 USLT / FLAC VorbisComment），双语字幕自动合并，逐行高亮三色方案，歌词预读偏移可调。

精准同步

灵活播放控制

5 种播放模式（顺序 / 列表循环 / 单曲循环 / 随机 / 关闭循环），进度条点击拖动 seek，全局快捷键支持自定义。

随心掌控

迷你播放器 & 详情页

独立小窗模式始终置顶，封面取色 + 毛玻璃背景；播放详情页底部滑入，左侧封面信息 + 右侧逐行歌词，体验沉浸。

精致体验

个性化设置

外观（循环模式/音量条透明度、关闭最小化到托盘）、播放（歌词预读偏移、跨来源跟踪）、快捷键自定义、OTA 在线更新一应俱全。

自由定制

OTA 在线更新

基于 libcurl 的在线更新功能，支持手动检查更新并下载安装最新版本，始终保持最佳体验。
