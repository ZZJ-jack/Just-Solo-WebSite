✨ 核心能力

从音频引擎到系统集成，每一处都精心打磨

高性能音频引擎

基于 miniaudio 单头文件库，支持 MP3 / FLAC / WAV / OGG / AAC / M4A / WMA / Opus。

24-bit 直通

智能音乐库管理

自动去重、多歌手合并、全局搜索高亮、手动拖拽排序，五列自适应布局。

音质标签

高级歌词系统

外部 .lrc / 嵌入式歌词，双语字幕，逐字三色高亮，预读偏移可调。

逐字高亮

深度 Windows 集成

SMTC 系统控件、NSD 灵动岛、LyricServer WebSocket 协议、系统托盘。

Win11 原生

播放控制

  • 5 种播放模式（顺序 / 循环 / 单曲 / 随机 / 关闭）
  • 全局快捷键（可自定义）
  • 进度条点击 / 拖动 seek
  • 热插拔恢复：设备拔出自动冻结

收藏 & 历史

  • 收藏 / 取消收藏，持久化存储
