✨ 核心能力

从音频引擎到系统集成，每一处都精心打磨

高性能音频引擎

基于 miniaudio 轻量库，替代 Qt Multimedia，支持 MP3 / FLAC / WAV / OGG / AAC / M4A / WMA / Opus。流式播放，24-bit 直通。

流式加载

智能音乐库管理

自动去重、多歌手合并、全局搜索高亮、手动拖拽排序，五列自适应布局。支持文件/文件夹拖放导入。

音质标签

完善的歌词系统

外部 .lrc / 嵌入式歌词，双语字幕合并，逐行三色高亮（已播黄/当前青/未播灰蓝），预读偏移 50~350ms 可调。

逐行高亮

迷你播放器

全新独立小窗模式，始终置顶，展示封面、歌曲标题与歌手，支持播放/暂停控制，可从详情页或托盘进入。

始终置顶

深度 Windows 集成

SMTC 系统控件、NSD 灵动岛歌词同步、Just Solo LyricServer 协议（WebSocket）、系统托盘、单实例检测。

Win11 原生

播放控制

  • 5 种播放模式（顺序 / 循环 / 单曲 / 随机 / 关闭）
  • 全局快捷键（可自定义）
  • 进度条点击 / 拖动 seek
  • 支持热插拔：设备插拔不中断播放

收藏 & 历史

  • 收藏 / 取消收藏，持久化存储
  • 播放历史自动记录，上限 500 条
  • 启动自动恢复上次播放列表
  • 跨来源跟踪，智能去重

界面 & 体验

  • 全新ui设计语言，带来更好的视觉体验
  • 原生支持深色主题
  • 丝滑ui动画，让每一刻都Just Solo
  • 系统原生标题栏（Win11 三色定制/Win10强制深色）

技术栈

  • C++17 + Qt 6.8.3
  • QML 现代界面，GPU 渲染
  • libcurl (OTA 在线更新) + cmark-gfm (Markdown 渲染)
  • CMake 构建，MSVC 编译

更多功能

  • 自定义播放列表：侧边栏创建/重命名/删除，从音乐库多选导入，持久化到 JSON
  • OTA 在线更新：基于 libcurl，支持检查更新并下载安装最新版本
  • Markdown 转富文本：基于 cmark-gfm，更新日志以富文本 HTML 展示
  • 设置页面：外观设置、播放设置、快捷键自定义、软件更新、关于信息
